# Verification: legacy prototype → Next.js

**Date:** 2026-11-05. **Browsers:** Google Chrome and Microsoft Edge (system installs) driven by `playwright-core`, Windows 11. All tests ran against static builds served by the same small Node static server (directory index, `404.html` fallback, no caching).

- **Legacy baseline:** the original ChatGPT Sites project (Vite + vinext + Cloudflare worker, `app/page.tsx` + `app/globals.css`), built with its own pinned toolchain (`pnpm install --frozen-lockfile`, `vinext build`). It was served once by `wrangler dev` to capture the server-rendered HTML, then frozen as static files (captured HTML plus the built client assets). That snapshot hydrates and runs without errors.
- **New site:** `npm run build` → `out/`.

## Method

| Check           | How                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Pixels          | Full-page screenshots at 1600, 1280, 1024, 768, 390 and 320 px, plus UI states. Reduced motion; lazy images forced to load; `img.decode()`, `document.fonts.ready` and running animations awaited. Software raster (`--disable-gpu --force-color-profile=srgb --disable-lcd-text`), and each screenshot is retaken until two consecutive captures are byte-identical. Every case is captured twice per site in fresh contexts; it **passes only if a legacy capture and a new capture are byte-identical** (pixelmatch `threshold: 0`, anti-aliasing counted). Legacy-vs-legacy and new-vs-new differences are recorded as the noise floor. |
| DOM             | Canonical serialisation of `<body>`: elements with sorted attributes, every text node kept separate (React text-node boundaries affect text shaping). Asset-only `<img>` attributes (`src`, `width`/`height`, `loading`, `decoding`, `data-nimg`, `style`) are excluded.                                                                                                                                                                                                                                                                                                                                                                    |
| Computed styles | `getComputedStyle` for every element plus `::before`/`::after` (about 360 properties each), and every element's page box, aligned by DOM path. Font-family names are normalised (`"DM Sans"` ↔ next/font's `dmSans`).                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Behaviour       | 36 scripted scenarios run identically on both sites; the JSON outcomes are compared.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Navigation      | Hash-link scrolling, Back, the 404 page, client-side navigation, 4xx responses (browser and server log), console errors and hydration warnings.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| CSS split       | Every pair of rules whose relative order changed when the stylesheet was split into partials, and that shares a property at equal specificity, was checked against the real DOM in 15 UI states for an element matching both.                                                                                                                                                                                                                                                                                                                                                                                                               |

### Intended differences

- **Mobile menu:** Escape closes it and returns focus to the toggle; widening past 800 px closes it; route changes close it. The toggle gained `type="button"` and `aria-controls="site-nav"`, and the nav gained `id="site-nav"`.
- **Size toggle buttons:** gained `aria-pressed`, so screen readers announce the selection. Every button gained `type="button"`.
- **`<body class="antialiased">`:** dropped. It was an unused Tailwind utility with no CSS behind it.
- **404 page:** the legacy site showed the framework's unstyled “404: This page could not be found.” The new site shows a styled page built from existing classes.
- **`<head>`:** added theme-color, canonical, Open Graph and Twitter cards, and LocalBusiness JSON-LD. Fonts are self-hosted and preloaded instead of loaded through a Google Fonts `@import`. The legacy title, description, `noindex, nofollow` and favicon are unchanged.

### Investigated and explained

- **Capture noise:** the first pixel run (GPU raster, single capture) showed differences that moved between runs. Examples: the office photo's resampling (max channel delta 24–29) and text anti-aliasing intensity (glyph positions identical). The same differences appeared between two captures of the _legacy_ site, so they were capture artefacts. Making the capture deterministic (above) brought every case to byte-identical.
- **CSS cascade:** the legacy stylesheet is a stack of override layers, so later base rules override earlier `@media` rules. Hoisting base rules above media blocks would have changed the mobile logo width, header padding, size-visual height and more. The split therefore keeps every partial in source order. One grouped mobile rule (`.feature, .guide, .story, .faq, .quote, .moving`) had to be split per section; that is the only change to rule structure.

## Cleanup (Phase 5)

- **Removed:** the Sites/vinext/Cloudflare scaffolding (unused shadcn components, connectors, D1/drizzle, worker, Vite config, pnpm files), `.openai/`, `docs/generated-assets.json`, `public/`, the Google Fonts `@import`, and `.npmrc` (it disabled `npm audit`).
- **Dead CSS:** 20 never-matching selectors (`.hero-bottom*`, `.route*`, `.route-line*`, `h1 em`, `.image-caption span:last-child`, `.solution-tabs button[aria-selected]`) and 98 declarations that a later declaration on the same selector always overrides (for example `@media (max-width: 800px) .logo { width: 120px }`, which loses to the later `.logo { width: 150px }`). Order and structure were untouched. Computed styles were re-verified as identical in all 17 states afterwards.
- **Copy (owner decision):** preview wording removed. The footer no longer says “· Private design concept”. The quote note now begins “This form prepares an email draft.” instead of “This preview prepares an email draft.” The AI-image labels and the size-guide caveat were kept.
